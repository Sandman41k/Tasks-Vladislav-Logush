1. Чем отличаются JVM, JRE и JDK? Что из них нужно установить разработчику, а что — конечному пользователю?

 Ответ: JVM(Виртуальная машина) запускает и выполняет байт-код на конкретном компютере.

        JRE(Среда запуска) = JVM + библиотеки. Нужна что бы открывать готовые программы.

        JDK(Комплект разработчика) = JRE + инструменты (компилятор javac, дебагер). Нужен для написания кода.

        - пользователю ничего устонавливать не надо (в современных программах JRE уже встроена внутри)
        - разработчику нужно устонавливать только JDK

2. Что такое байт-код и почему говорят, что Java — «Write Once, Run Anywhere»?

 Ответ: Байт-код — это универсальный промежуточный код, в который компилятор превращает текст программы (.java → .class).
        Он написан не для процессора, а для JVM.

        «Write Once, Run Anywhere» означает, что Java-код не привязан к конкретной операционной системе:
            1. Компилирует код в один универсальный файл байт-кода.
            2. Этот файл можно запустить на Windows, Mac или Linux без изменений.
            3. JVM на каждом устройстве сама переводит этот байт-код в команды, понятные конкретному процессору.
